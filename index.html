Cloudflare Worker einrichten (einmalig, kostenlos)

  1. workers.cloudflare.com → kostenlosen Account erstellen
  2. "Create a Worker" → Inhalt von worker.js einfügen → Deploy
  3. Im Worker-Dashboard: Settings → Variables → SERPAPI_KEY = API-Key eintragen (als Secret)
  4. Die angezeigte Worker-URL unten eintragen (https://….workers.dev)
